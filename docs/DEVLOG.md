## 2026-10-17 — 관리자 페이지 (`/sqld/admin/`)
- 관리자 로그인(일반 회원과 별개 `admins` 테이블, bcrypt, 실패 제한, CSRF 토큰). 첫 계정 admin / 초기 비밀번호는 install.php 가 관리자가 없을 때만 생성, 비밀번호 바꾸기 전까지 상단 경고.
- 메뉴: 대시보드(회원·시험·문제·강의 통계, 자격증별 현황, 최근 가입/시험) · 회원(검색, 닉네임/요금제/만료일 수정, 기록 초기화, 회원 삭제) · 시험 기록(필터, 상세 문항, 삭제, 비회원/방치 시험 정리) · 문제(필터·검색, 정답률, 추가/수정/숨김) · 강의(추가/수정/미리보기/숨김) · 자격증(기본 정보·시간·합격 기준·색·공개, 과목별 실전 문항 수, 단원 공부 팁, 새 자격증) · 관리자 계정(비밀번호 변경, 관리자 추가/삭제).
- 관리자가 고친 자격증·단원·문제·강의는 `admin_edited = 1` → install.php 를 다시 실행해도 JSON 원본으로 덮어쓰지 않음.

## 2026-10-17 — 회원 탈퇴
- 닉네임 화면 아래 '회원 탈퇴' 카드 추가 → `withdraw.php`(POST, 확인 칸에 '탈퇴' 입력 + 확인창). 본인 계정과 시험·문항·강의 진도·자격증 설정을 한 트랜잭션으로 삭제 후 로그아웃. 문제은행·강의는 유지. 카카오 쪽 앱 연결은 남아 있어서 다시 카카오로 로그인하면 새 가입으로 처리.

## 2026-10-17 — 첫 가입 시 닉네임 직접 설정
- 카카오로 처음 가입하면 무조건 닉네임 설정 화면(`nickname.php`)으로 이동. 카카오 닉네임이 한글 2~10자이고 안 겹치면 입력칸에 미리 채워 두고, 그대로 쓰거나 바꿀 수 있음. 저장 전에는 다른 페이지로 못 감.
- 저장하면 '가입 완료! ○○님, 환영해.' 안내와 함께 원래 보던 페이지로 이동. 닉네임 정하기 전 상단에는 내부 아이디 대신 '닉네임 설정 중' 표시.

## 2026-10-17 — 로그인 화면 없애고 카카오 버튼으로 바로 로그인
- 상단바 '로그인 / 무료 가입' 버튼 → **카카오로 로그인** 버튼 하나로 교체(누르면 지금 보던 페이지로 돌아옴). 홈·결과·실전 모의고사 카드의 가입 버튼도 카카오 버튼으로.
- `login.php`, `register.php` 는 화면 없이 바로 `kakao_login.php` 로 넘김(예전 링크 호환). 로그인이 필요한 페이지에 들어가면 곧장 카카오 로그인으로.
- 카카오 취소·실패 시에는 홈으로 돌아와 안내 문구 표시, 로그아웃 후에도 홈으로.

## 2026-10-17 — 아이디 로그인 폐지, 예전 계정·기록 정리
- 로그인도 카카오로만: `login.php` 는 카카오 버튼만 남김(아이디/비밀번호 POST 처리 삭제). 카카오 계정 연결 기능(`?link=1`)과 '첫 가입자가 주인 없는 예전 기록을 가져가는' 규칙도 삭제.
- `currentUser()` 는 `kakao_id` 가 있는 회원만 로그인으로 인정 → 예전 아이디 계정 세션은 자동으로 로그아웃 상태.
- 예전 계정·기록 삭제용 1회 스크립트 `sql/cleanup_legacy_accounts.sql` 추가 (카카오 없는 회원 + 그 시험/문항/강의 진도/시험일 + 주인 없는 옛 기록 + 로그인 실패 기록 삭제). 서버에서 백업 후 직접 실행.

## 2026-10-17 — 아이디 회원가입 폐지 (카카오로 일원화)
- `register.php` 는 가입 폼 없이 '카카오로 시작하기' 안내 화면으로 변경 (POST 가입 처리 삭제 → 새 아이디 계정 생성 불가). 기존 링크(무료 가입 등)는 그대로 이 화면으로 연결.
- `login.php`: 카카오 로그인 버튼을 위에, 아이디/비밀번호 로그인은 '예전에 아이디로 가입했다면' 접힘 영역으로 (기존 회원 보호용으로 유지).
- 기존 아이디 회원 → 카카오 연결: 닉네임 화면의 '카카오 계정 연결하기'(`kakao_login.php?link=1`) → 콜백에서 현재 계정에 `kakao_id` 연결. 이미 다른 계정에 연결된 카카오면 거부. 아이디 로그인 시 연결 안내 문구 표시.

## 2026-10-17 — 카카오 로그인
- 로그인·회원가입 화면에 '카카오로 로그인' 버튼(카카오 디자인 가이드 색상) 추가. REST API 방식: `kakao_login.php`(state 생성) → 카카오 → `kakao_callback.php`(state 검증, 토큰 발급 시 client_secret 포함, 회원번호·닉네임 조회).
- 처음 온 카카오 회원은 자동 가입(아이디 `kakao+회원번호`, 비밀번호 임의 값). 카카오 닉네임이 한글 2~10자이고 중복이 없으면 그대로 쓰고, 아니면 닉네임 설정 화면으로. 비회원 기록 이전도 동일하게 적용.
- DB: `users.kakao_id` (UNIQUE) — `install.php` 실행 시 자동 추가. 설정은 `config.php` 의 `KAKAO_*` 3개 (자동 배포 대상이 아니라 서버에 별도 반영).
- 검증: 가짜 카카오 서버로 신규 가입·재로그인(중복 계정 없음)·영문/중복 닉네임 → 닉네임 설정·취소·위조 state·로그인 후 원래 페이지 복귀·비회원 기록 이전을 브라우저 자동 테스트로 확인.

## 2026-10-10 — v3.0 IT 자격증 플랫폼 PassLog 로 확장
- **브랜딩**: 서비스명 후보 5개(PassLog·CertiRoad·합각·Q-Level·itPass) 중 PassLog(패스로그) 임시 적용, SVG 로고/심볼/파비콘 제작, 상수(`BRAND_*`)로 교체 가능.
- **자격증 5종**: SQLD + 정보처리기사 필기, ADsP, 리눅스마스터 2급, 네트워크관리사 2급 필기. 자격증별 과목·실전 문항 수·시간·합격/과락 기준 설정(`data/certs.json`), 상단 자격증 선택.
- **콘텐츠**: 신규 문제 558개(정처기 180, ADsP 117, 리눅스 150, 네관 111) + 강의 92개(SQLD 22 포함). 자체 제작, 계산/코드 문제 실행 검증 후 별도 검수(힌트 정답 노출 100건 수정, 해설 오류 2건 수정).
- **난이도 선택**: 시험 시작 화면/대시보드/홈 카드에서 혼합·하·중·상 바로 선택. 부족하면 가까운 난이도로 채우고 알림.
- **비회원**: 로그인 없이 1회 최대 20문제 연습 + 결과표(과목별 표, 틀린 유형, 해설). 가입/로그인 시 비회원 기록 자동 이전. 실전 모의고사·기록·오답·분석은 로그인 필요.
- **실전 프로세스**: 실제 문항 수/시간 그대로, 문제별 타임아웃(서버 시계 기준, 0초면 자동 제출), 현재 문제만 전달·되돌아가기 불가, **일시정지**(시계 정지·문제 숨김) → 결과표에 일시정지 횟수/총 시간, 시간 초과 수, 평균 풀이 시간, 문제별 소요 시간 표시. 연습에서도 타이머 선택 가능.
- **학습**: 자격증 → 과목 → 단원 → 강의 목차, 진도율(전체/과목별), 학습 완료 표시, 읽던 위치 자동 저장 → '이어서 공부하기'로 그 위치부터 복원. 분석/결과에서 '강의 보기', '이 단원만 풀기' 연결.
- **PDO 전면 정리**: 모든 쿼리를 `q()` 헬퍼(진짜 prepared statement + 타입 바인딩)로 통일, 문자열 이어 붙이던 SQL 제거.

- **문서**: `docs/SPEC.md`(유저 플로우·사양), `docs/DB.md`(ERD·명세), `docs/DEVLOG.md`(이 파일) 체계로 변경.
